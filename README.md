# terroir

<!-- badges: end -->

**Geo-point environmental and agricultural-economics data collector.** Hand
`terroir` a coordinate and a date range and get back a tidy, provenance-stamped
series of climate, weather, vegetation-index, soil, elevation or
agricultural-economics data, pulled from many **free** sources behind one
contract.

`terroir` is the **data-collector member** of the ORCHESTRA -- a producer that
supplies covariates and forcings to `flexyBayes`, `kernR` and `PESTO`. See
`../CONSTELLATION_MEMBER.md` and the contract spec `inst/geo_point_contract.md`
(C6).

## Installation

```r
# install.packages("remotes")
remotes::install_github("max578/terroir")
```

## Minimal example

```r
library(terroir)

req <- geo_point_request(
  lon = 138.6, lat = -34.92,        # Adelaide
  start = "2020-01-01", end = "2020-01-10",
  variables = c("T2M", "PRECTOTCORR"),
  source = "nasapower"
)

# offline = TRUE answers from a shipped fixture -- no network egress,
# no source package required. Drop it (or set offline = FALSE) for a live pull.
series <- collect_point(req, offline = TRUE)
series
```

## Design

- **One contract (C6).** `geo_point_request()` -> `collect_point()` ->
  `geo_point_series` (a tidy `data.table` with a fixed schema + mandatory
  provenance, validated by `verify_geo_series()`).
- **Sources are optional adapters.** Each source package is in `Suggests`; terroir
  builds and `R CMD check`s clean with none installed. A missing source returns a
  structured refusal, never an error (`is_refusal()`).
- **Free-only.** `register_source()` refuses any adapter that is not free.
- **Offline replay.** `offline = TRUE` answers from a recorded fixture with zero
  network egress -- reproducible pipelines, continuous integration, and sovereign
  coordinates that must never reach an upstream service.
- **Sovereign coordinates.** `sovereign = TRUE` coarsens an exact GPS point to
  roughly a one-kilometre cell before any upstream call; both the raw and the
  coarsened point are kept in provenance.

## Sources

Implemented adapters: `nasapower` (global climate + solar), `silo` (weatherOz /
SILO 5 km grid, Australia), `abares` (read.abares gridded farm economics),
`modis` (MODISTools NDVI/EVI), `stac` (rsi / Sentinel-2 via Planetary Computer),
`nert` (TERN soil, soil-moisture, actual-evapotranspiration, canopy height and
phenology, Australia), `ocular` (Sentinel-2 / Landsat spectral-index series over
a 500 m window via the Microsoft Planetary Computer, cloud-masked). Enrolled and
landing in a future release: GSODR, geodata (WorldClim + SoilGrids + elevation),
chirps.

## Status

`terroir` 0.3.0. The contract machinery, offline replay and coordinate
coarsening are complete and tested; `nasapower`, `modis`, `abares` and `stac`
are verified end-to-end against recorded goldens, and `ocular` against a live
two-sensor regression pilot. Live golden fixtures for the network/key adapters
are regenerated by `data-raw/regenerate_golden.R`.
